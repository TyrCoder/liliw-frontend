12 System Manual §4

All 42 tables in the live database, one domain at a time. Solid lines are real foreign-key constraints — there are only four in the whole schema. Dashed lines are logical relationships the application code enforces on its own: a shared email, a status looked up by a public attraction id, or a content_type/content_id pair standing in for a foreign key Postgres never declared. Thin cross-referenced boxes (no attribute list) point to a table detailed in another panel.

2 of 7 — Content
